========================================================================
🔌 คู่มือการติดตั้งและใช้งานแบบออฟไลน์ 100% (Thai Food Maintenance Portable Setup Guide)
========================================================================

ยินดีต้อนรับสู่ระบบซ่อมบำรุงโรงงานอาหาร (Thai Food Maintenance System)
แอปพลิเคชันนี้ทำงานแบบ "Offline-First" 100% และถูกปรับปรุงให้เป็นแบบ "Portable" 

คุณสามารถบันทึก คัดลอก ย้าย หรือก๊อปปี้โฟลเดอร์โครงการนี้ไปวางที่เครื่องคอมพิวเตอร์เครื่องอื่นๆ 
(ผ่าน USB Drive, Google Drive, Shared Folder) แล้วเปิดใช้งานได้ทันทีโดยไม่ต้องตั้งค่าให้ยุ่งยาก!

------------------------------------------------------------------------
🚀 วิธีเริ่มใช้งานแบบง่ายที่สุด: แบบ Portable (ดับเบิ้ลคลิกเพื่อรันได้ทันที)
------------------------------------------------------------------------
เราได้เตรียมสคริปต์อัตโนมัติมาให้คุณรันใช้งานได้ในคลิกเดียวโดยไม่ต้องพิมพ์คำสั่งใน Terminal เอง:

💻 สำหรับผู้ใช้ Windows (PC ทั่วไป):
1. เข้าไปในโฟลเดอร์โปรเจกต์นี้
2. ดับเบิ้ลคลิกไฟล์ "start_app.bat"
3. ระบบจะตรวจสอบส่วนสำคัญ และจำลองเว็บเซิร์ฟเวอร์ขึ้นมา พร้อมเปิดเบราว์เซอร์เข้าสู่แอปให้คุณโดยอัตโนมัติ!

🍎 สำหรับผู้ใช้ macOS / Linux:
1. เปิด Terminal ในโฟลเดอร์นี้
2. พิมพ์คำสั่ง sh start_app.sh หรือดับเบิ้ลคลิกไฟล์ "start_app.sh"
3. ระบบจะทำงานและเปิดเบราว์เซอร์ขึ้นมาให้คุณทันที!

------------------------------------------------------------------------
📌 สิ่งที่ต้องมีติดเครื่อง (System Requirements)
------------------------------------------------------------------------
- เครื่องคอมพิวเตอร์ของคุณจำเป็นต้องมี "Node.js" ติดตั้งอยู่ (ลงเพียงครั้งเดียวในเครื่องนั้นๆ)
  * ดาวน์โหลดได้ฟรีและปลอดภัยที่: https://nodejs.org (เลือกเวอร์ชัน LTS ที่แนะนำสำหรับผู้ใช้ทั่วไป)
  * หากเปิดไฟล์ start_app แล้วพบว่ายังไม่มี Node.js ระบบจะเปิดหน้าเว็บดังกล่าวเพื่อให้คุณดาวน์โหลดและกดติดตั้งได้ในทันที

------------------------------------------------------------------------
🛠 ขั้นตอนการเริ่มใช้งานแบบแมนนวล (Manual Setup สำหรับนักพัฒนา)
------------------------------------------------------------------------
หากคุณไม่ต้องการใช้ไฟล์ดับเบิ้ลคลิกแบบ Portable สามารถเปิด Command Prompt หรือ Terminal ขึ้นมาและทำตามขั้นตอนนี้:

ขั้นตอนที่ 1: เข้าสู่โฟลเดอร์โปรเจกต์
- พิมพ์ cd ตามด้วยที่อยู่โฟลเดอร์ของคุณ เช่น:
  cd C:\ThaiFoodMaint

ขั้นตอนที่ 2: ติดตั้ง Dependencies (ทำเฉพาะครั้งแรกที่ลงเครื่องใหม่)
- พิมพ์คำสั่งแล้วกด Enter:
  npm install

ขั้นตอนที่ 3: สตาร์ทแอปพลิเคชันแบบออฟไลน์
- พิมพ์คำสั่งแล้วกด Enter:
  npm run dev

ขั้นตอนที่ 4: เข้าใช้งานผ่านเว็บเบราว์เซอร์
- เปิด Google Chrome หรือ Microsoft Edge แล้วไปที่ลิงก์:
  http://localhost:3000

------------------------------------------------------------------------
🏢 การแชร์และนำไปรันบนวงเครือข่ายภายในบริษัท (Intranet Production Build)
------------------------------------------------------------------------
หากคุณต้องการประกอบร่างโค้ดออกมาเป็นหน้าเว็บสำเร็จรูปที่ปลอดภัย 100% เพื่อไปแชร์ผ่านเซิร์ฟเวอร์ของบริษัท (Intranet/LAN) โดยที่เครื่องปลายทางไม่จำเป็นต้องมี Node.js:

1. เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
   npm run build
2. ระบบจะรวบรวมไฟล์ทั้งหมดและสร้างโฟลเดอร์ใหม่ชื่อ "dist" ขึ้นมา
3. คุณสามารถคัดลอกเฉพาะโฟลเดอร์ "dist" นี้ ไปอัปโหลดขึ้นเว็บเซิร์ฟเวอร์ใดก็ได้ในบริษัท 
   (พนักงานหรือช่างทุกคนจะสามารถเปิดลิงก์และใช้งานระบบได้ทันที ปลอดภัย ข้อมูลเป็นส่วนตัวในเครือข่ายบริษัท 100%)

------------------------------------------------------------------------
💾 เคล็ดลับการสำรองข้อมูล (Backup & Anti-Data Loss Tips)
------------------------------------------------------------------------
- ข้อมูลทั้งหมด (เช่น ทะเบียนเครื่องจักร, แผน PM, บันทึกใบสั่งซ่อม, ตารางกะช่าง) จะถูกเก็บบน "LocalStorage" ของเว็บเบราว์เซอร์ในเครื่องคอมพิวเตอร์นั้นๆ
- เพื่อความปลอดภัย แนะนำให้ทำตามคำแนะนำต่อไปนี้:
  1. ใช้ปุ่ม "ส่งออก Excel / XLSX" ที่อยู่ในตารางและรายงานต่างๆ เพื่อดึงข้อมูลออกไปเก็บสำรองเป็นไฟล์ Excel
  2. หลีกเลี่ยงการสั่งล้างแคชหรือล้างประวัติเบราว์เซอร์แบบ "ลบข้อมูลแอปพลิเคชันที่บันทึกไว้" (Hosted app data)
  3. แนะนำให้บุ๊กมาร์ก (Bookmark) ลิงก์ http://localhost:3000 ไว้บนเบราว์เซอร์เพื่อความสะดวกรวดเร็วในการเข้าใช้งานครั้งต่อไป

ขอให้ทุกท่านประสบความสำเร็จในการบริหารจัดการงานบำรุงรักษาโรงงานครับ!
